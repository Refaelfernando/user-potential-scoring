Profil Lengkap Tier

Menghitung...
Angka "baseline kirim saat ini" di tabel aksi dihitung dari rata-rata Sent Jul per user ÷ estimasi minggu berjalan. Angka rekomendasi frekuensi = baseline data + kaidah umum anti-fatigue campaign (bukan murni statistik) — sebaiknya divalidasi A/B test kecil dulu, terutama untuk tier Medium. Kolom "Konten/Keyword Hari Ini" berisi angle pesan yang rotasi otomatis tiap hari (beda per tier) dari pool 5 tema (dana darurat, kebutuhan mendesak, modal usaha, pendidikan, renovasi) — ini draft angle, bukan copy final; sebaiknya tetap direview tim compliance/legal sebelum dipakai, terutama terkait aturan periklanan pinjaman online yang berlaku.
Metodologi: WOE (Weight of Evidence) binning + Logistic Regression, dilatih dari data historis periode lengkap terakhir yang terdeteksi otomatis dari kolom sheet — model di-retrain otomatis tiap refresh dari data terbaru (lihat "Status Training Model" & "Lihat bukti statistik" di atas untuk detail & drift-nya). Fitur: (1) Segment/cohort recency berdasarkan hari sejak Paidback Date, (2) tahap engagement terjauh periode berjalan (Sent → Delivered → Read). Tiga filter bisa di-toggle lewat tombol di header: (1) flag khusus di kolom Noted kalau ada di sheet, (2) user yang gagal delivered 2 periode berturut-turut (Jun & Jul) — indikasi nomor bermasalah, dan (3) user yang sudah Created bulan ini (takeout dari list supaya gak di-follow-up lagi). Ketiganya cuma memengaruhi kartu/tier/daftar User ID yang tampil — training model tetap pakai data lengkap tanpa filter ini. Semua metrik engagement (Sent/Delivered/Read) berasal dari channel WhatsApp saja — rekomendasi di atas spesifik untuk strategi WhatsApp, belum mencakup channel lain.
Dashboard ini hanya menghitung ulang (re-apply) formula yang sudah ada — bukan melatih ulang model. Untuk update bobot model, model perlu dilatih ulang secara terpisah oleh analyst dan konstanta di bagian atas script (WOE / koefisien) diperbarui manual.
