Menghitung...
Angka "baseline kirim saat ini" di tabel aksi dihitung dari rata-rata Sent Jul per user ÷ estimasi minggu berjalan. Angka rekomendasi frekuensi = baseline data + kaidah umum anti-fatigue campaign (bukan murni statistik) — sebaiknya divalidasi A/B test kecil dulu, terutama untuk tier Medium.
Metodologi: WOE (Weight of Evidence) binning + Logistic Regression, dilatih dari data historis Created Jun 2026 (bobot tetap; AUC & KS divalidasi ulang tiap refresh terhadap data terbaru — lihat "Lihat bukti statistik" di atas). Fitur: (1) Segment/cohort recency berdasarkan hari sejak Paidback Date, (2) tahap engagement terjauh periode berjalan (Sent → Delivered → Read). Skor dihitung ulang otomatis setiap dashboard dibuka, mengikuti data terbaru di Google Sheet — bobot model bersifat tetap (tidak retrain otomatis) supaya hasil konsisten & mudah diaudit; retrain manual direkomendasikan tiap kuartal atau saat tim data mengonfirmasi data baru (mis. OCS Score yang sudah dibersihkan) siap dipakai. User dengan flag khusus di kolom Noted (mis. "Dont Touch!") otomatis dikecualikan dari scoring kalau kolom itu ada di sheet — saat ini kolom Noted sudah dihapus dari sheet sehingga tidak ada user yang dikecualikan. Semua metrik engagement (Sent/Delivered/Read) berasal dari channel WhatsApp saja — rekomendasi di atas spesifik untuk strategi WhatsApp, belum mencakup channel lain.
Dashboard ini hanya menghitung ulang (re-apply) formula yang sudah ada — bukan melatih ulang model. Untuk update bobot model, model perlu dilatih ulang secara terpisah oleh analyst dan konstanta di bagian atas script (WOE / koefisien) diperbarui manual.
