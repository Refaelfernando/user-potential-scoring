Metodologi: WOE (Weight of Evidence) binning + Logistic Regression, dilatih dari data historis Created Jun 2026 (AUC 0.84, KS 0.54). Fitur: (1) Segment/cohort recency berdasarkan hari sejak Paidback Date, (2) tahap engagement terjauh periode berjalan (Sent → Delivered → Read). Skor dihitung ulang otomatis setiap dashboard dibuka, mengikuti data terbaru di Google Sheet — bobot model bersifat tetap (tidak retrain otomatis) supaya hasil konsisten & mudah diaudit; retrain manual direkomendasikan tiap kuartal atau saat tim data mengonfirmasi data baru (mis. OCS Score yang sudah dibersihkan) siap dipakai. User dengan flag Dont Touch! otomatis dikecualikan dari scoring.
Dashboard ini hanya menghitung ulang (re-apply) formula yang sudah ada — bukan melatih ulang model. Untuk update bobot model, model perlu dilatih ulang secara terpisah oleh analyst dan konstanta di bagian atas script (WOE / koefisien) diperbarui manual.
